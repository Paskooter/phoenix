Phoenix is an independent, non-commercial, clean-room reimplementation of a cloud service that was shut down in 2019. It is distributed as source code so that owners of the affected hardware can run a compatible service themselves.

6. Third-party services

Phoenix can be configured to reach outside services — for example map tiles, weather, news or traffic providers — because the robot's own features depend on that data. Those services are operated by other people, under their own terms, and this project makes no promise about their availability, accuracy or conduct.

Which of them an instance contacts is a configuration decision made by whoever runs it. The software is built so that each one degrades visibly rather than silently when it cannot be reached.
