candidate's original 14-case comparison:

  treats malformed JSON as `{}`, and lets null produce the source error path.
  The public SigV4 front door must remain a separately defined deployment
  adapter; it is not evidence for this original internal boundary.
- Original target extraction uses `split('.')[1]` and lowercases only the
  first character. The candidate's last-component/full-lowercase dispatch
  changes missing-dot, extra-dot, casing and unknown-target responses.
- Executing the actual original event constructor/Joi contract on 98 inputs
  produced 65 differences, including 14 acceptance differences. Hand-written
  email/date/optional-field validation needs repair.
- The 14-case comparator sorts JSON keys and omits content-length, ETag,
  keep-alive and Date; nine raw JSON body key orders differ. That result cannot
  certify the complete wire response.
- The original startup hook defers Account/Loop events with `setImmediate`
  after the save hook and uses the original SNS sender. An HTTP event sink
  is a deployment extension; full startup/SNS execution is unverified.
