# N-08 candidate: source grammar metadata normalization

Status: **working candidate; unverified and awaiting lead review**
Owner: Luna Max
Base: `54459ca561c9e217e380384f43abf8283c54476c`
Reference revision: `5c0a7390539663ba749d360de348a428c088505c`

This bounded candidate repairs three source interpretation gaps in the NLU
grammar engine:

- `priorityRank` now trims and compares priority tags case-insensitively.
  The pinned report source uses `priority='high'`; preserving its spelling as
  an unrecognized value demoted personal-report matches below launch
  catch-alls.
- Rule literals and character-class variants undergo the same punctuation
  normalization as input tokenization. This makes source forms such as
  `[u?.s?.]` and `[b?.e?.t?.]` match ordinary `us` and `bet` ASR text while
  retaining the source grammar's optional variants.
- Quoted semantic-action literals are trimmed. The pinned chitchat source has
  incidental trailing spaces in `whyDidJiboAction ` and `JiboBirth ` action
  values; those spaces must not become public intent/entity values.

The changes are limited to `packages/nlu/src/grammar/matcher.js`,
`packages/nlu/src/grammar/parser.js`, and focused request-parser tests. No
resource, oracle, harness, golden, tracker, lockfile, or robot data changed.

## Failure classification

The stored lead HTTP replay in
`.parity/reviews/full-parser-integration.json` covers 20,528 cases, with
20,127 matches and 401 differences. Its group totals are:

| Group | Cases | Matches | Differences |
| --- | ---: | ---: | ---: |
| boundary | 21 | 20 | 1 |
| chitchat | 11,432 | 11,189 | 243 |
| hub-client | 9,002 | 8,865 | 137 |
| report | 73 | 53 | 20 |

Those differences contain 256 unique `(text, rules)` pairs. The boundary
difference is the known full-name loop result (`who is jane jetson`). The
remaining failures are concentrated in chitchat and hub-client launch
arbitration: multiple source arms match the same words but the local
intra-grammar score selects a different arm or entity, finite factory word
lists cannot cover arbitrary names, and a smaller set needs loop/entity
postprocessing parity. The report group is the clearest bounded source fix:
all 20 report differences are priority demotions. Punctuation and action-value
normalization address source-backed event/entity rows without adding utterance
special cases.

Replaying the 401 stored difference rows directly through this candidate gives
89 rows equal to the stored expected result. This is 87 of the 255 unique
non-boundary pairs; the row-level count includes duplicate hub-client cases.
The breakdown of rows fixed is report 20, chitchat 67, and hub-client 2.
This selected replay only evaluates prior difference rows; it does not test
for regressions among the 20,127 rows that previously matched, so the lead
must run the full integration replay after sequential merge.
