Owner: Luna Max

This candidate replaces the report subskill `{}` view stubs with the frozen
Pegasus weather, news, commute, and calendar view builders. It remains
unverified until the lead runs the integrated controls and renders the views
on Moth. No simulator authority, golden, comparator, or provider response was
changed.

## Source basis

The implementation follows the frozen compiled Node8 modules and their source:

- `packages/report-skill/src/subskills/weather/WeatherViews.ts` and
  `packages/report-skill/lib/subskills/weather/WeatherViews.js`
- `packages/report-skill/src/subskills/news/NewsViews.ts` and
  `packages/report-skill/lib/subskills/news/NewsViews.js`
- `packages/report-skill/src/subskills/commute/CommuteViews.ts` and
  `packages/report-skill/lib/subskills/commute/CommuteViews.js`
- `packages/report-skill/src/subskills/calendar/CalendarViews.ts` and
  `packages/report-skill/lib/subskills/calendar/CalendarViews.js`
- the six frozen JSON templates under `packages/report-skill/resources/views`

The copied templates retain the original Nimbus asset paths and schema. The
helper tests compare primitive outputs from the compiled source vectors for
temperature bands, AP image scaling, traffic bands, departure labels, event
icons, time placement, summary truncation, and `leaveEmpty` behavior.

## Candidate changes

- Added `weatherViews.js` and wired `WeatherMimLogic` to create the source
  `weatherTempView`, including hot/cold thresholds, icon paths, unit labels,
  and one/three-character temperature offsets.
- Added `newsViews.js` and wired `NewsMimLogic` to create one cloned
  `headlineView_N` per image-backed AP item, including category overlays,
  portrait/landscape geometry, and last-view close behavior.
- Added `commuteViews.js` and wired `CommuteMimLogic` to create the source
  `trafficView` and `departTimeView` configurations.
- Added `calendarViews.js` and wired `CalendarMimLogic` to create event cards,
  time-of-day card assets, icon-word matches, full-day handling, minute
  offsets, summary truncation, and single-skill eye-return behavior.
- Copied `weatherHiLo.json`, `newsHeadline.json`, `commuteTraffic.json`,
  `commuteDepart.json`, `calendarEvent.json`, and `calendarIconWords.json`
  byte-for-byte into the skills resources.

News provider data in the current Phoenix RSS/AP shim may contain a headline
without an image URL. The source helper requires the AP image source and
dimensions, so Phoenix records `newsImagesUnavailable`, keeps one empty view
slot per headline for the existing `shift()` expression, and continues the
spoken headline path. It does not invent an image or claim asset serving
parity. A provider that supplies valid AP image metadata receives the exact
source view configuration.

## Remaining scope

The view builders preserve the source Nimbus asset identifiers, but this
candidate does not provide an image server, validate Moth's asset bundle, or
claim hardware rendering parity. News image views remain dependent on AP
image metadata from the provider. The candidate does not alter report data
fetching, parsing, MIM phrasing, orchestration, or action envelopes. Lead
review should inspect the resolved `DISPLAY` contexts and render each view on
Moth before integration.
