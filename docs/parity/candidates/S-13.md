## Candidate changes

- Added `weatherViews.js` and wired `WeatherMimLogic` to create the source
  `weatherTempView`, including hot/cold thresholds, icon paths, unit labels,
  and one/three-character temperature offsets.
- Added `newsViews.js` and wired `NewsMimLogic` to create one cloned
  `headlineView_N` per image-backed AP item, including category overlays,
  portrait/landscape geometry, and last-view close behavior.
- Added `commuteViews.js` and wired `CommuteMimLogic` to create the source
  `trafficView` and `departTimeView` configurations.
- Added `calendarViews.js` and wired `CalendarMimLogic` to create event cards,
  time-of-day card assets, icon-word matches, full-day handling, minute
  offsets, summary truncation, and single-skill eye-return behavior.
- Copied `weatherHiLo.json`, `newsHeadline.json`, `commuteTraffic.json`,
  `commuteDepart.json`, `calendarEvent.json`, and `calendarIconWords.json`
  byte-for-byte into the skills resources.

News parsing now follows the source AP contract: entries without a complete
image are filtered, the first provider feed entry is removed as the header,
and only then are headlines passed to `newsViews`. `NewsMimLogic` propagates
view/template rejection like the source and does not create `{}` view slots or
set a `newsImagesUnavailable` flag. A provider that supplies valid AP image
metadata receives the exact source view configuration. The current Phoenix
RSS/AP shim emits no image metadata, so it remains an explicit provider
limitation and produces no playable news item.

The frozen Node 8.9.4 compiled modules were exercised with a JS-only edge
fixture using the pinned reference image. The observed source behavior was:

- `newsViews([])` rejects at the final `defaultSelect` mutation with a
  `TypeError` (`Cannot read property 'defaultSelect' of undefined`).
- An item without an `image` object rejects with a `TypeError` while reading
  `source`; a malformed dimension string still fulfills with `NaN` geometry.
- A valid item followed by an incomplete item rejects the whole map; no
  partial view list is returned.
- A rejected template dependency rejects `newsViews`, and a rejected
  `newsViews` dependency propagates through `NewsMimLogic` without fallback
  view data.
- `newsParse` filters missing/empty image metadata and, after filtering,
  removes the first feed entry. The candidate test
  `reportNews.source-errors.test.js` covers these boundaries.

## Remaining scope

The view builders preserve the source Nimbus asset identifiers, but this
candidate does not provide an image server, validate Moth's asset bundle, or
claim hardware rendering parity. News image views remain dependent on AP
image metadata from the provider; the current RSS shim's image-less entries
are filtered by the source parser. The candidate does not alter report data
fetching, MIM phrasing, orchestration, or action envelopes. The archived
Nimbus asset audit in `S-13-assets.md` records the missing calendar `tree`
asset and the loader requirements. The fresh recapture covers only the five
fixture-backed physical cases; the missing-source tree row, linked no-view
assertions, and weather/news revalidation rows remain outside it. The final
aggregate receipt and falsifier review must pass before S-13 can be verified.
