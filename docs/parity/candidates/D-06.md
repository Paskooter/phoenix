Status: **bounded provider repair; awaiting lead review**

Owner: Luna Max
Base: `7e4f203`
Reference revision: `5c0a7390539663ba749d360de348a428c088505c`
Audit date: 2026-09-05

This candidate repairs the replacement-feed boundary in
`packages/data/src/news.js`. The frozen AP handler returns upstream AP XML
unchanged after an authenticated request with `maxItems=10`; its consumer
expects AP entries with a feed/header entry and an image-bearing NITF content
tree. The Phoenix BBC/NPR adapter now carries provider media values into that
consumer shape.

## Adapter behavior

`parseRssItems` now recognizes provider media in RSS and Atom forms:

- `media:content` and `media:thumbnail` URL/source attributes;
- RSS `enclosure` URL attributes; and
- Atom `link rel="enclosure"` href attributes.

An image is retained only when the same provider element supplies a non-empty
URL, width, and height. `medium=video` and non-image MIME types are skipped.
The adapter preserves the provider strings byte-for-byte apart from XML entity
decoding and re-escaping in the AP response. It does not derive dimensions,
download an image, rewrite URLs, or use a different element's dimensions.

The AP-shaped response begins with an image-less entry from the provider feed
title when that title exists. This matches the source header boundary: the
entry has a title and `apcm:ExtendedHeadLine`, but no summary or media, so the
source parser excludes it before applying its existing header offset. Each
story with provider media gets a NITF content tree whose
`media-reference[1]` is the source parser's preview slot. Its source, width,
and height are the provider values; the surrounding role slots carry no
invented media attributes. Stories without complete provider media or a
provider summary remain incomplete and are filtered by the source parser.

## Source-consumer evidence

A JS-only fixture generated AP-shaped XML through the candidate adapter and
then ran the frozen compiled consumer in the pinned Node 8.9.4 image
(`node@sha256:8233daae003ba0ecba4e6d70cab8525c30a3f085935afc624a275892ebe23f7c`).
The fixture used three image-bearing stories plus a feed title. The original
`xml2js` parser, `NewsParse`, and `NewsViews` returned:

```text
runtime: v8.9.4
parsedHeadlines: ["Two", "Three"]
viewImageSources: ["https://cdn.example.test/two.jpg",
                   "https://cdn.example.test/three.jpg"]
views: 2
```

An independent Atom fixture with three `link rel="enclosure"` stories
produced the same source result for `Atom two` and `Atom three`, with the
corresponding `atom-two.jpg` and `atom-three.jpg` URLs. These checks exercise
the actual frozen Node 8 consumer rather than only matching output strings.

A bounded read-only provider check on 2026-09-05 found:

| provider feed | parsed items | items with complete image metadata | frozen consumer result |
| --- | ---: | ---: | --- |
| BBC general RSS | 10 | 10 | 9 stories and 9 views after source filtering/header offset |
| NPR national RSS | 10 | 0 | no playable source news items |

The provider feeds are mutable and were not committed as fixtures or treated
as golden data. The BBC result demonstrates the repaired boundary can reach
the original view builder; the NPR result remains a provider limitation when
the current feed supplies no dimensions or image URLs.

## Validation and remaining scope

```text
node --test packages/data/test/news.test.js
# 10 passed, 0 failed

node --test packages/data/test/*.test.js
# 31 passed, 0 failed
```

The tests cover RSS media content, thumbnail and enclosure forms, Atom
enclosure links, video rejection, missing-dimension preservation, AP header
construction, XML escaping, omitted-summary preservation, and the relay
envelope/cache path.

The adapter remains a replacement provider, not a complete AP relay. It does
not reproduce AP media IDs, attribution, full/preview/thumbnail variants,
management metadata, authenticated AP URLs, hourly category polling, or the
original poller's cache refresh and shutdown lifecycle. Those differences
remain open D-06 work. No story, image URL, or dimension is synthesized to
hide a provider gap.
