This candidate repairs the source-observable PromptData, fixed-offset
DateTime, Location, loop partial-state, and natural-language wrapper paths.
It remains unverified until the lead completes integrated production and
hardware checks. It does not claim report-calendar, provider, or complete S-05

## Source basis

The implementation follows the frozen reference files:

- `packages/baseskill/src/graph/mims/utils/slimmer/PromptData.ts` builds
  `dt`, `location.home`, `loop`, `speaker`, `referent`, and `jibo` from the
  runtime context. Date/location and loop construction are separate guarded
  blocks. A missing ISO is accepted by the source Moment path, while a bad
  non-empty ISO clears only date/location data.
- `packages/baseskill/src/graph/mims/utils/slimmer/LooperData.ts` and
  `NLData.ts` define birthday/birthdate formatting, age units and
  supplemented values, zodiac text, emotion values, and ordered loop walks.
  User matches are assigned during the walk, so the last duplicate ID wins;
  fields assigned before a malformed user remains visible after the guard
  catches the later error.
- The pinned `jibo-data-utils` DateTime and Location implementations define
  fixed-offset local fields, ISO week ordinals, the permissive seasonal
  `isInRange` branches, long-period phrasing, JIBO_HOME string behavior, and
  region methods.

The frozen source hashes and before/after differential record are retained in
[`S-05-source-differential-20260905.json`](S-05-source-differential-20260905.json).

## Candidate changes

- `promptData.js` now keeps the source date/location and loop try blocks
  independent. It accepts source-shaped absent, null, empty, and numeric ISO
  values, retains loop/Jibo/speaker state assigned before malformed user data,
  walks users in source order, and selects the last duplicate ID.
- `dateTime.js` now ports the source `isInRange` branch algorithm, including
  invalid numeric month/day behavior, and implements year, month, week, and
  weekend `toString` values plus source `prefixOnAt` handling.
- `locationData.js` now implements JIBO_HOME equality, `isLocal`, source
  standard-name/prefix/string behavior, and `toLog`.
- Missing Jibo emotion data follows source `EmotionData` direct field access,
  so the guarded loop is empty when the emotion object is absent.
- The dependency-free `nlData.js` age and zodiac wrappers remain source-shaped;
  fresh omitted/null/empty/boolean/numeric/date-only/offset/invalid/leap-day
  birthdate probes found no additional mismatch.

No resource bytes, provider adapters, report calendar code, comparator,
goldens, reference/consumer symlinks, or dependency files were changed.

## Remaining S-05 scope

The implementation honors the explicit offset carried by each runtime ISO and
does not implement an IANA timezone database or infer a zone from latitude and
longitude. Report calendar/provider helpers and full production MIM action
parity remain separate work. The broader jibo-data-utils NLU parser and
mutation-only methods outside the exercised PromptData/MIM surface are also
outside this candidate. Source-shaped standalone MIM tests and the focused
differential controls pass, but this candidate remains unverified pending lead
review and integrated controls.
