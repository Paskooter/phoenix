# N-08 portable compiled-FST data candidate

Status: candidate unverified; pending root review. This is a data-loading slice
of the explicit `compiled-fst` profile. It does not change the default AST
profile or claim full N-08 parity.

The candidate adds a versioned JSON representation of the decoded OpenFST
`vector/standard` structures already consumed by the compiled-FST executor. The
format preserves header fields, ordered input/output symbol bytes, state and
arc order, destinations, final/arc weights, and the `BigInt`, `NaN`, positive
infinity, negative infinity, and negative-zero values that JSON would otherwise
lose. Symbol bytes use canonical base64. A profile manifest records the format
version, graph/factory source labels, raw source hashes and sizes, snapshot
hashes and sizes, the pinned inventory, and the existing source/reference/native
provenance.

`PHOENIX_NLU_COMPILED_SNAPSHOT_MANIFEST` is an explicit opt-in runtime setting.
It cannot be combined with the binary artifact settings. The loader validates
the manifest schema and profile, the pinned inventory hash, all 98 public graph
entries, every snapshot hash/size/provenance field, and the complete 16-file
factory directory identity. It decodes all 15 factory FST snapshots into the
same `ConnectedFstExecutor` interface; `factory_list.txt` is retained as a
hashed auxiliary provenance entry and is not executable data. Graph executors
are constructed lazily after the complete manifest pass. Binary loading and
the default AST path retain their existing behavior.

The exporter is
`packages/nlu/tools/exportCompiledFstSnapshots.mjs`. It requires explicit
inventory, rules-directory, factory-directory, and output arguments. The
private export used for these controls is recorded at
`.parity/reviews/n08-fst-json-20260907/profile-v2/profile.json`; no JSON graph
artifacts are committed. The manifest has no absolute or private source paths.

The export contains 98 public graphs and 15 decoded factory FSTs. The 44.0 MB
of source graph files becomes 170.1 MB of graph JSON; the 2.44 MB factory
directory becomes 9.32 MB of FST JSON plus the auxiliary file's metadata. The
complete snapshot data and 43 KB profile manifest total 179.5 MB, about 3.87×
the source graph/factory bytes. The complete size and hash receipt is
`.parity/reviews/n08-fst-json-20260907/export-report.json`.
